# Недельный отчёт по поиску работы

## Что считать (отдельно для потоков А и Б)

| Показатель | Поток А | Поток Б |
|---|---|---|
| Найдено подходящих вакансий | | |
| Отправлено откликов | | |
| Живых ответов (приглашение, вопрос, тестовое) | | |
| Анкет и автоответов | | |
| Отказов | | |
| Без ответа больше 7 дней | | |

Источник: раздел «Отклики» на hh.ru, чаты, очередь и лог Радара, слова пользователя.

## Мерило

Сравни с мерилом из профиля: например, «15 откликов по потоку А и 2 живых ответа до такой-то даты». Выполнено / не выполнено / сколько осталось.

## Выводы

1–3 наблюдения на цифрах, например:
- «По потоку А 12 откликов, 0 живых ответов: письма или резюме не цепляют — проверить первый абзац писем».
- «Половина отказов из-за английского — добавить в стоп-лист обязательный B2».

## Одно изменение на неделю

Одно конкретное действие: новые запросы, другой порог, правка резюме, другой первый абзац писем. Одно, чтобы через неделю было понятно, сработало ли.

## Честность

Не округляй в хорошую сторону. Ноль ответов — это ноль, и это полезная информация.
