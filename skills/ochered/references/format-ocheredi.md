# Формат таблицы очереди

## Столбцы

| Столбец | Что внутри |
|---|---|
| Поток | А или Б. Заливка: А — светло-зелёная, Б — светло-серая |
| Компания / вакансия | «Компания, Название вакансии» |
| Ссылка | Кликабельная ссылка на вакансию (гиперссылка, а не просто текст) |
| Город и формат | «СПб, гибрид», «Москва, удалённо» |
| Зарплата | Как в вакансии, с пометкой «на руки» или «до вычета» |
| Резюме | Какое резюме выбрать при отклике |
| Текст письма | Готовое письмо |
| Добавлено | Дата |

Строки: сначала поток А, внутри — по приоритету ниш из профиля; потом поток Б.

Отдельный лист «Спорные»: компания, ссылка, вопрос к пользователю, черновик письма (после ответа «откликаемся» вакансия переносится на основной лист). Отдельный лист «Отклонённые» по желанию пользователя: компания, причина.

## Оформление Excel

- Шрифт Arial, шапка жирная с заливкой, закреплённая первая строка.
- Ширина столбца «Текст письма» около 90 символов, перенос текста включён, высота строк увеличена под письмо.
- Ссылки — через гиперссылку ячейки.
- Имя файла постоянное, чтобы пользователь каждый день получал обновлённую версию.

Если в сессии есть навык для работы с Excel (xlsx) — используй его.

## Сообщение к файлу

2–4 строки: всего в очереди, новых сегодня (из них поток А), что решить пользователю, сколько он отправил с прошлого раза.
